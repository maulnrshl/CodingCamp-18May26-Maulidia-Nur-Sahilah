# ✨ To-Do List Life Dashboard

A cute and aesthetic productivity dashboard website built using HTML, CSS, and Vanilla JavaScript.  
This dashboard helps users stay productive with a Pomodoro timer, to-do list, quick links, and daily motivation.


## 🌸 Features

### ✅ Greeting & Clock
- Real-time clock and date
- Dynamic greeting based on time

### ✅ Pomodoro Timer
- 25-minute focus timer
- Start, stop, and reset buttons

### ✅ To-Do List
- Add tasks
- Mark tasks as completed
- Delete tasks
- Prevent duplicate tasks
- Tasks saved using Local Storage

### ✅ Quick Links
- Add favorite website links
- Open links in new tabs
- Links saved using Local Storage

### ✅ Daily Motivation
- Inspirational quote section

### ✅ Responsive Design
- Works on desktop and mobile devices

---

## 💻 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
